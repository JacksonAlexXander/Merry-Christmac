# MediaPipe Hand Landmarker

This directory contains the unmodified browser runtime from [@mediapipe/tasks-vision 0.10.21](https://registry.npmjs.org/@mediapipe/tasks-vision/-/tasks-vision-0.10.21.tgz) and Google's [Hand Landmarker model bundle](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task). See the [Hand Landmarker documentation](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker) and [Apache 2.0 license](LICENSE).
